# 筋トレ記録

単独で動くローカル筋トレ記録アプリです。バックエンドもログインも無く、
記録は全てこのブラウザ(この端末)の中だけに保存されます。

## 使い方

**一番簡単な方法**: `index.html` をダブルクリックしてブラウザで開くだけです。

もしそれでうまく開かない・レイアウトが崩れる場合は、フォルダの中で以下を実行し、
表示されたURL(`http://localhost:8000` など)をブラウザで開いてください。

```
python3 -m http.server 8000
```
(Pythonが無い場合は `npx serve` でも代用できます)

## iOSアプリとして使う

このリポジトリは Capacitor のiOSプロジェクトを同梱しており、**App Store配布もできる
ネイティブアプリ**としてビルドできます。通信先が1つも無く、フォントも同梱済みなので、
初回起動から機内モードで完結します。

ビルドにはMacとXcodeが必要です。手順・審査の注意点・この構成の考え方は
**[IOS.md](IOS.md)** にまとめてあります。

```sh
npm install
npm run sync      # Web の中身を iOS プロジェクトへ流し込む
npx cap open ios  # Xcode で開く
```

## 更新について

ホーム画面に追加して開くとアドレスバーが無く、ブラウザの再読み込みボタンが
使えません。新しい版を配信しても手元で更新できないと困るので、次の2つを
用意しています。

- 起動するたびにサーバーへ問い合わせ、最新のファイルを取りに行きます
  (`sw.js`。オフライン時だけ手元のキャッシュで起動します)
- それでも古いままの場合は、画面一番下の **「最新の状態に更新」** を押すと
  キャッシュを消して読み込み直します。その下に表示されている「最終更新」が
  実際に配信されているファイルの日時です

## 制限事項

- レスト終了時の「バックグラウンド通知バナー」だけは、`index.html` を直接
  ダブルクリックして開いた場合(`file://`)は動作しません。ブラウザの仕組み上、
  通知機能は `http://localhost` のような形で開いた場合のみ有効になります。
  音・バイブレーション・画面内のアラーム表示はダブルクリックのままでも
  問題なく動作します。
- データはこの端末のこのブラウザにのみ保存されます(localStorage)。他の
  端末や他のブラウザとは同期しません。ブラウザの「閲覧データを削除」を
  行うと記録も消えるのでご注意ください。

## 機能

- ルーティーン管理: 1〜数日分のトレーニングメニューを作成・編集。↑↓で
  並べ替えた順番どおりに、次に行うメニューが自動的に選ばれます
- 今日のトレーニング: 種目ごとに重量・回数を記録、自己ベスト更新時は
  次回のデフォルト重量に自動反映
- レストタイマー: セット間の休憩時間をカウントダウン、終了時に音・
  バイブレーション・画面フラッシュで通知
- 成長グラフ: 種目ごとの過去の記録推移をグラフ表示
